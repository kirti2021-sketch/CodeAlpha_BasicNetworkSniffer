# Basic Network Sniffer

## Project Overview
This project is a Basic Network Sniffer developed using Python.
It captures network packets and displays important packet information.

## Objective
The main objective of this project is to understand how network packets work and identify different network protocols.

## Technologies Used
- Python
- Scapy Library
- VS Code

## Features
- Captures network packets.
- Displays Source IP Address.
- Displays Destination IP Address.
- Identifies TCP, UDP and ICMP protocols.
- Displays packet size.
- Counts total captured packets.
- Generates a packet report in a text file.

## How to Run

1. Install Python.
2. Install Scapy using:

   py -m pip install scapy

3. Open the project folder in VS Code.
4. Run the following command:

   py network_sniffer.py

## Output
The program captures 10 network packets and generates a report named packet_report.txt.
